This portfolio showcases my skills, projects, experience, education, and professional journey as a developer. It is designed to provide a clean, modern, and responsive experience for recruiters, employers, and anyone interested in my work.

* Responsive design for desktop, tablet, and mobile
* Smooth navigation and user interactions
* Project showcase
* Skills and technologies
* Education and experience
* Contact information
* Links to my professional profiles

## ⚙️ Run the Project Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL provided by Vite, usually:

```text
http://localhost:5173
```

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
